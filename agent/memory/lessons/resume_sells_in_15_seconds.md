## Core idea

Resume = **marketing tool**, not biography. Every line must sell. Recruiter answers in first ~5s:

1. Do role titles match the vacancy / path look coherent?  
2. Tenure OK (not 3-month hops)?  
3. Location / geo fit?  
4. Only then — stack and details.

---

## Must-have structure

| Block | Rule |
|-------|------|
| Contacts | Working email, phone, LinkedIn, GitHub, portfolio |
| Title | Market name of role (comma-separated if several): e.g. `Senior Product Engineer \| Senior Frontend Engineer` |
| Goal | One concrete line: what role, where, domain — not philosophy |
| About | 3–4 sentences: who / can / seek / unique |
| Experience | Company + **one prestige/scale line** + role + dates + **1-line achievement bullets** with active verbs + numbers |
| Skills | Relevant only; **bottom** of resume; no soft-skills fluff |
| Education | Relevant only; fewer courses |

## Achievement bullets

- Active verbs: запустил, увеличил, создал, внедрил, снизил, собрал, довёл  
- Prefer numbers; if hard — use volume / time / process approaches:  
  - volume: «3 клиента», «десятки залов», «команда FE из 3»  
  - process: «убрал Excel из ключевого контура», «миграция Vite самим»  
- Ban vague: значительно, много, хорошо, successfully, proven track record, team player…  
- «Улучшил продукт» → what + how much / for whom

Company line tip: short **scale hook** + hyperlink to company site (Top-N, MAU, domain).

## ATS / visual

- One column; selectable-text PDF; left-align; role title matches JD when applying  
- No complex tables/columns that break parsers  
- Bullets ideally **one line**; bold company/role/key metrics  
- Senior: max 2–3 pages  

## Remove from public resume

Age/DOB, home address, family, kids, weak languages, “references on request”.  
(Guide also de-emphasizes education dates for some markets — RF HH often still wants education.)

## LinkedIn headline (not philosophy)

`Role | stack | geo | industry | years if 7+`  
Avoid: Ex-Google flex, soft skills, “helping companies grow”.

## ATS simulators (optional check per vacancy)

CV Wolf, JobScan, SkillSyncer, Cultivated Culture, Resume Worded — paste resume + JD, fill missing keywords **honestly**.
