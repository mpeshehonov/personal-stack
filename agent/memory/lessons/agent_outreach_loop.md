# Lesson: agent outreach loop (2026-07-30)

## Что сломалось

Daily-агент 7+ дней копировал одну мантру: `/jobs like → /cover → ручной send`, хотя:

- статусы лидов в БД не менялись;
- `job_applications` был пустой (сопроводы из чата/кнопок не всегда попадали в SQLite);
- человек уже откликался снаружи — воронка врала (`applied=0`).

## Правила

1. Перед советом читать `job_leads.status`, `job_applications`, feedback.
2. Не повторять вчерашний shortlist-совет, если факты не изменились.
3. Если есть `applied` без `interview` → follow-up, не like/cover.
4. Сопровод только через `/cover` / кнопку / «сопровод 42» — чтобы черновик писался в БД.
5. Отклик снаружи → «Откликнулся» / «откликнулся 76».
