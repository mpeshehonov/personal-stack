# Cover letter (сопроводительное)

## Goal

Рекрутер читает десятки откликов. За 15–20 секунд должно быть ясно: ты подходишь, есть один кейс под JD, понятно как связаться. Не второе резюме и не текст из ChatGPT.

## When to use

- `/cover <id|url|текст>` в Telegram
- Email apply (`hr@…`)
- Поле сопроводительного на HH / Habr
- Отклик в Telegram (ЛС рекрутеру)
- User вставил текст вакансии или ссылку и просит сопровод

## Inputs (read before writing)

1. Полный текст вакансии (или URL → содержимое)
2. `site/content/resume/resume.json` + `agent/memory/career-copy-notes.md` — факты
3. **Один** опыт + при необходимости второй короткий факт под JD (не весь список работодателей)
4. Канал: `hh` | `tg` | `email` — от этого длина и подпись
5. Контакт из вакансии (TG/email), если есть — упомянуть «куда» только вне тела письма

**Hard rules:** только факты из резюме / career-copy-notes. Не придумывать годы, работодателей, инструменты. Нет Vue как основного стека, Bitrix24 как текущего фокуса, 3+ года Python — если этого нет в резюме.

## Channels and length (не путать!)

| Канал | Цель | Ориентир | Жёсткий потолок |
|-------|------|----------|-----------------|
| `hh` / Habr поле | сопровод в форме отклика | **900–1500** символов (~120–200 слов), 3–5 коротких абзацев | HH технически до **10 000**; **не** резать до 400/500 |
| `tg` | готово к копипасту в ЛС | **700–1200** символов, приветствие + кейс + контакты | без воды |
| `email` | письмо на hr@ | **120–180** слов, тема отдельно | — |

**Миф:** «на HH максимум 400/500 символов» — **ложный**. Это устаревший/выдуманный лимит. Не пиши ультракороткие однострочники для HH, если канал `hh`.

Короткий формат (~350–500 символов) — **только** если user явно просит «очень короткий» / «в одну строку».

## Russian: работодатели и предлоги

Опыт **в компании** — предлог **«в»**, не «на»:

| Правильно | Неправильно |
|-----------|-------------|
| В X5 Tech делал… | На X5 делал… |
| В Citilink переносил… | На Citilink… |
| В НЛМК собирал SPA… | На НЛМК… |
| В BI.ZONE делал… | На BI.ZONE… |
| В POTALONU веду… | На POTALONU… |

«На» — для сайта/платформы как объекта, не как места работы: «на сайте citilink.ru», «на платформе ЭДО». Для роли в компании всегда **в**.

Имена компаний писать как в JD/резюме; не склонять латиницу криво.

## AI-маркеры: запрещено

### Символы и оформление

| Запрещено | Чем заменить |
|-----------|--------------|
| Длинное тире `—` | запятая, точка или дефис `-` |
| Среднее тире `–` в диапазонах | `3-5`, `140-180` |
| Стрелки `→` `←` `=>` `->` | «на», «в», «через» или ничего |
| Точка по центру `·` | запята или перенос |
| `\|` как разделитель | перенос строки |
| Маркированные списки в теле | связный текст абзацами |
| `...` многоточие | не использовать |
| Emoji | никогда |
| Markdown bold/headers в теле для копипаста | plain text |

### Слова и шаблоны (AI slop)

- «Меня заинтересовала ваша вакансия» / «I am writing to express»
- «уникальная возможность», «динамичная команда», «профессиональный рост»
- «обладаю уверенными/глубокими знаниями», «обширный опыт»
- «командный игрок», «горящие глаза», «быстро обучаюсь»
- «буду рад стать частью вашей команды»
- «внесу вклад в развитие продукта»
- «не только X, но и Y»
- «важно отметить», «следует подчеркнуть», «в заключение»
- «релевантный кейс:» как заголовок

### Структурные маркеры

- Одинаковая длина всех предложений
- Ровно 3 абзаца по 2 предложения «как в учебнике»
- 15 технологий через слэш в одном предложении
- Повтор summary из резюме целиком
- Пересказ всего карьерного пути

## Structure

### HH / Habr (`hh`)

Без «Здравствуйте» можно (поле формы). 3–5 абзацев:

1. Кем откликаешься + одна деталь из их JD (продукт/стек/задача)
2. Один named proof под JD (где, что, стек из вакансии своими словами)
3. При необходимости второй короткий факт
4. Формат: удалённо, Сочи; готовность выйти
5. Ссылка на резюме (и TG по желанию)

### Telegram (`tg`)

```
Здравствуйте!

Пишу по вакансии [роль] [в компании, если есть]. [одна деталь из JD].

[1 кейс под JD]

[формат / город / выход]

Резюме: https://mpeshekhonov.ru/ru/resume
Telegram: @makusimu_san

С уважением,
Максим Пешехонов
+7 950 919-67-86
```

### Email (`email`)

## Fit gate (перед текстом)

Если вакансия явно мимо профиля (не FE, office-only при remote-only, вилка сильно ниже min, XML/XSLT вместо React, скам-сигналы) — **сначала** короткий вердикт «не откликайся / риски», и только по явной просьбе user дать минимальный текст.

Если user сказал «без комментариев» и канал ясен — выдай **только** тело сопровода, без meta.
